FITUR.TXT
=========

NAMA KONSEP
-----------
Aplikasi penyimpanan file universal dengan tampilan depan berupa kalkulator.
Aplikasi berfungsi sebagai kalkulator normal, tetapi memiliki akses tersembunyi
menuju Vault untuk menyimpan, mengelola, melihat, dan mengedit berbagai jenis
file secara lokal.

PRINSIP UTAMA
-------------
1. Gratis
2. Offline-first
3. Tidak membutuhkan akun
4. Tidak membutuhkan server/cloud
5. File disimpan secara lokal
6. Data Vault diusahakan tetap tersedia setelah aplikasi di-uninstall lalu
   di-install kembali
7. Mendukung berbagai jenis file tanpa membatasi extension tertentu
8. Kalkulator tetap berfungsi normal sebagai kamuflase
9. Vault memiliki sistem keamanan tersendiri
10. Database hanya digunakan untuk metadata/index, bukan sebagai tempat utama
    penyimpanan file

Kalkulator harus terlihat dan terasa seperti aplikasi kalkulator sungguhan,
sehingga pengguna lain tidak langsung mengetahui adanya Vault.

==================================================
2. HIDDEN VAULT UNLOCK
==================================================

Vault tidak ditampilkan secara langsung pada halaman utama.

Pengguna dapat memasukkan secret tertentu melalui kalkulator.

Contoh:

1234 =
    ↓
Vault terbuka

Jika input bukan secret:

123 + 456 =
    ↓
579

Input biasa tetap diproses sebagai kalkulasi normal.

Sistem unlock dapat mendukung:
- PIN
- Secret expression
- Pattern/sequence
- Gesture
- Biometric sebagai metode tambahan

Secret tidak ditampilkan secara jelas pada UI.

Jika memungkinkan, sistem keamanan tidak menyimpan secret dalam bentuk
plain text.

==================================================
18. PERSISTENT STORAGE
==================================================

File Vault harus dirancang agar tidak bergantung pada private app storage
sebagai satu-satunya tempat penyimpanan.

Tujuan:

Install aplikasi
    ↓
Import file
    ↓
Uninstall aplikasi
    ↓
Install kembali
    ↓
Aplikasi mendeteksi Vault yang sudah ada
    ↓
File kembali ditampilkan

Aplikasi memiliki fitur untuk melakukan scan dan membangun ulang index
apabila database metadata hilang atau rusak.

CATATAN:
Kemampuan mempertahankan file setelah uninstall bergantung pada lokasi
penyimpanan dan perilaku Android. Aplikasi harus menggunakan storage yang
sesuai untuk data yang memang ingin dipertahankan.
